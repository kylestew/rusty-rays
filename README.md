# Rusty Rays

A Rust executable project for ray tracing.

## Getting Started

### Prerequisites

- Rust and Cargo (install from [https://rustup.rs/](https://rustup.rs/))

### Building

```bash
cargo build
```

### Running

```bash
cargo run
```

## Project Structure

- `src/main.rs`: Entry point for the application
- `Cargo.toml`: Project configuration and dependencies
